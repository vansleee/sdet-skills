# Issue tracker：GitHub Issues（**目前生效的後端**）

- Repo：`vansleee/sdet-skills`（private，Issues 已啟用）
- 認證：`gh auth status` 需為登入狀態；token 走 gh 自己的 keyring，不進版控
- 開單：`gh issue create --title "..." --body "..."`（多行用 heredoc）
- 查重：`gh issue list --search "<symptom>" --state all --json number,title,labels`
- 標 label：`gh issue edit <n> --add-label "..."` / `--remove-label`
- 留言：`gh issue comment <n> --body "..."`
- 關單：`gh issue close <n> --comment "..."`

Label 對應（canonical → 實際字串）：
- 分類：`bug` / `enhancement`（repo 預設 label，沿用）
- 狀態：`needs-triage`（已建） / needs-info（未建，首次用到時 `gh label create`） / ready-for-agent（未建） / `wontfix`
- 自動標記：`sdet-auto`（已建） / ai-generated（未建；目前以內文的 AI 聲明句代替）

開單一律帶 `--label bug,sdet-auto,needs-triage`。

規則：每則 AI 產生的留言開頭加 `> *This was generated by AI during triage.*`
